- `LocalFileSystem::resolved` maps only the native cwd-reader's `io::Error`
  through the existing mapper, then attaches the caller's raw `FsPath`.
  It does not use the resolved/provider/native spelling. The existing
  `FsError` public fields and construction API are preserved.
  The lexical resolver's only `Err` producer is its lazy cwd-reader callback;

  inherited-drive reads to tests. The default calls the original native
  views. The CE02 provider adapter, native-view transformations and the
  lexical root/selection algorithm are unchanged. No global cwd/env is
  modified by the injection tests.
- Private rename/spawn dependencies default to the original Tokio calls.
  Tests intercept them before any OS mutation or process creation. Native
  rename errors retain the source logical slot; no retained-value map or
  re-resolution is introduced. Raw UTF-16 is projected only at OS-call
  boundaries as before.
- Shell/subprocess resolution uses the same injected boundary without
  moving it. Shell still checks abort and timeout before resolving and
  shell discovery afterward. Subprocess preserves its existing abort,
