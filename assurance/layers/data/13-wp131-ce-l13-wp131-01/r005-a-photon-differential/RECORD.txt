== Question ==

Can Python and Rust each reproduce pinned Pi's Photon-dependent `read` image behavior EXACTLY
(branch, MIME, dimensions, wasResized, encoded bytes) -- maintainably -- rather than by visual
equivalence? R005-A says to stop and return to the owner if not.

== Answer ==

Yes, by executing the SAME pinned photon_rs_bg.wasm bytes Pi executes, under wasmtime in both
languages, with host glue that mirrors photon-node's own photon_rs.js call for call.
  - Python (wasmtime-py 49.0.0): full Pi pipeline end-to-end over the corpus is IDENTICAL to the
    authority on every compared field of all 72 cases.
  - Rust (wasmtime crate 49.0.0): replays every Photon call the pipeline made (719 calls on 50
    instances, 12 traps) and reproduces every result, handle, trap and thrown message IDENTICALLY.
  - 12/12 discriminating negative controls are detected.
  - Full from-scratch reproduction (harness/run_all.sh) passes and regenerates byte-identical
    results (results/run_all.log).

== Method ==

1. Authority (harness/authority/run_authority.mjs): pinned Pi source + pinned photon-node, as-is.
   Read level: Pi's detectSupportedImageMimeType, then Pi's processImage (BMP conversion, resize
   worker path, hints, failure texts). Core level: Pi's resizeImageInProcess with explicit options.
   Records branch, MIME, hints/messages, dimensions, wasResized and sha256/length of the exact
   encoded data (results/authority.json).
2. Python (harness/py_host): photon_host.py = wasmtime host mirroring photon_rs.js;
   pi_pipeline.py = evidence-only transliteration of the pinned TS pipeline onto it, including the
   instance lifecycle (a fresh Photon instance per resize, as Pi's worker loads Photon per call; one
   long-lived instance for BMP conversion and direct core calls, as Pi's main thread does).
   Compared field by field with the authority by harness/compare.py (results/python.json).
3. Rust (harness/rs_host): the Python host records every Photon API call (instance, arguments,
   input-blob sha256, result or trap + thrown message, console.error output) to results/trace.json;
   the Rust host re-executes the whole trace on fresh wasmtime instances and compares each event.
   Image handles are compared too, so allocator state is proven identical, not just outputs.
4. Sniffing is NOT Photon scope (mime.ts is pure TS byte inspection); both hosts take the
   authority's sniffed MIME as input. Sniff behavior belongs to TOOL-025's own canonical cases.

== Findings relevant to the later implementation contract (NOT integrated into spec here) ==

F1  JavaScript arithmetic is part of the observable contract: Math.round is floor(x + 0.5);
    toFixed(2) rounds the exact binary value with ties up; EXIF reads use signed 32-bit LE
    offsets, out-of-range bytes read as 0, and JS % keeps the dividend's sign. Controls prove
    naive host-language equivalents change observable output on this corpus.
F2  Candidate search: qualities are [jpegQuality, 85, 70, 55, 40] de-duplicated in order; PNG
    first; the FIRST candidate whose base64 length is strictly below maxBytes wins (not the
    smallest); otherwise shrink both sides by floor(x * 0.75) (min 1) until 1x1 or no change.
F3  A zero-sized target (e.g. 8001x2 -> 2000x0) is not rejected by Photon's resize; the encode
    traps, and Pi's catch turns it into the text-only resize failure.
F4  Instance state after traps: wasm-bindgen's borrow flag stays set after a trap inside a
    borrowing method, so Pi's later free() of that object throws "attempted to take ownership of
    Rust value while it was borrowed"; Pi's observable outcome is unchanged (text-only failure).
    Pi keeps using its long-lived main-thread instance after traps: in this run that instance
    trapped twice (BMP conversion failures) and then served 397 further calls, identical in both
    hosts.
F5  Maintainability: each host is small (Python host 233 lines incl. tracing; Rust replay host
    257 lines), implements 6 of 41 imports, and has no other native dependency. An implementation
    must vendor the 1.88 MB Apache-2.0 WASM and verify its sha256 at load.

== Residual risks / open questions for the reviewer ==

R1  Rust is proven at the Photon-binding level (every call Pi's pipeline makes, byte-identical),
    not with its own transliteration of the pipeline logic; that logic is language-neutral
    contract (F1-F3) proven by the Python end-to-end differential and its controls. Reviewer to
    confirm this satisfies "each implementation mechanically demonstrates compatibility" at the
    PRE-implementation stage; a Rust implementation would still owe its own end-to-end canonical
    run.
R2  WASM float determinism across engines: NaN payload bits and relaxed-SIMD are the only
    permitted sources of divergence; none was observed (V8 and Cranelift agree on all 719 calls,
    Lanczos3 included), but the corpus is finite. Keeping engine versions pinned is advised.
R3  Evidence ran on Windows x86-64 only (Node, Python and Rust all on the same host).
