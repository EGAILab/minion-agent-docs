## Defect and change

The Rust helper passed `kill -KILL -<pid>` to the external executable. A
negative group operand without an option terminator is ambiguous to procps-ng
4.0.2. The controlled regression demonstrated successful helper status while
the addressed ready parent remained alive. The initial unisolated known-bad
test run instead ended with `Killed`, which is also recorded rather than
misreported as an ordinary assertion failure. The subsequent isolated control
is the reproducible, assertion-based negative evidence.

The production change adds `--`: `kill -KILL -- -<pid>`. No other production
logic changes: Windows taskkill, process-group creation, monitor/fallback,
spawn-time cancellation, first-claim classification and disposal are untouched.

## Permanent witness and control

Linux unit witness in `execution/subprocess.rs`:
`group_kill_terminates_ready_parent_and_pipe_holding_descendant`.

It creates a new process group containing a shell and a long-lived descendant.
The shell reports the descendant PID before the helper is invoked. The test
requires helper success, the parent's signal termination (`code == None`), and
EOF from the descendant-held pipe. Readiness is a handshake, not a sleep/retry
assertion. A failed run uses the corrected explicit group operand to clean up
before asserting, rather than leaking the fixture.

`scripts/l12-d003-negative-control.py` copies the workspace, conformance fixtures
and existing compile-time fixture into a disposable directory, removes only the
option terminator, compiles the actual unit binary, then runs that binary in a
new session. Compilation/setup errors do not count as killed mutants. Isolation
is necessary because the rejected helper may signal the caller's group.

On Debian bookworm / procps-ng 4.0.2 / Rust 1.97.1:

- Candidate witness: 1 passed, 0 failed.
- Compiled missing-option-terminator mutant: 0 passed, 1 failed; exit 101;
  `the ready parent must be killed: Elapsed(())` (six-second failed parent/EOF
  observation window, followed by cleanup).
- The script leaves candidate sources unchanged; full gates rebuild the positive
  package after the mutant.
