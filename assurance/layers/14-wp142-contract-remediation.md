## WP142-R003 (medium): the schema did not enforce the string protocol

- **Schema:** the `{"utf16": …}` envelope is removed, since the domain no longer needs it, and the
  schema now rejects it. Strings are plain JSON strings.
- **Preflight:** a normative, language-neutral preflight rejects any document holding a code point
  in U+D800..U+DFFF, keys included. JSON Schema patterns cannot express this portably.
- **Controls:**
  - negative: lone high and lone low surrogates in a skill description, `expected`, `base`, a tool
    snippet and a section, each rejected by the preflight and accepted by the schema alone;
  - positive: astral characters and a paired `😀` escape, accepted.
